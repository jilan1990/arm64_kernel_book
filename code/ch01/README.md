# ch01 导论：为什么要写自己的操作系统 — 本章代码快照

## 本章主题
本章是导论，讲解为什么要从零写一个操作系统、为什么选择 ARM64 + QEMU、本书的目标与组织结构。

## 本章无独立代码
本章不包含任何内核代码，也没有可编译的工程文件。下一章（ch02）将开始搭建开发环境。

## 下一章起点
从 ch02 开始安装交叉编译工具链、QEMU 和 GDB，验证开发环境可用。

---

### 本章涉及的概念性内容（非构建文件，摘自书稿）

本书共 19 章，目标是从零实现一个可在 QEMU ARM64 virt 平台上运行的操作系统内核，包含：启动与初始化、PL011 UART 驱动、异常与中断（GICv2）、物理内存页分配器、slab 内核分配器、进程管理与上下文切换、优先级抢占调度、系统调用、自旋锁与信号量、字符/块设备模型、tmpfs 文件系统、用户 Shell、精简网络栈（ARP/IP/ICMP/UDP + virtio-net）。

- 目标架构：ARM64（AArch64）
- 模拟平台：QEMU `virt` 机器，Cortex-A57，256MB RAM
- 内核加载地址：`0x40080000`
- 开发主机：x86_64 Linux，使用 `aarch64-none-elf-` 交叉工具链
